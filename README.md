# ⚙️ Getting Started

## Prerequisites

- Node.js (18 or above)
- Angular CLI (19+)

## Clone Repository

```bash
git clone https://github.com/nvnpalani/portfolio.git
```

## Navigate

```bash
cd portfolio
```

## Install Packages

```bash
npm install
```

## Run Project

```bash
npm start
```

or

```bash
ng serve
```

Open your browser:

```
http://localhost:4200
```
